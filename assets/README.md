## Concept image slots
Place the three concept images in `assets/concepts/` using these base names
with extension `.jpg`, `.jpeg`, `.png`, or `.webp`:
- `phanya-laos-sour-mash-whiskey`
- `two-palms-tropical-hazy-ipa`
- `shimapan-highball-club`

The deck builders will auto-load these files into the concept gallery slide:
- `python3 scripts/build_avi_consulting_deck.py`
- `python3 scripts/build_avi_consulting_pdf.py`
